零、结论（用户 2026-10-06 已确认）：**学校这台能开光遇**
--------------------------------------------------------
用户原话：「学校的那台电脑换了 cpu 和主板可以开光遇的，不过核心没有以前多，
单核性能强。」

历史记录（按日期，别被旧条目误导）：
  * 2026-09-01：学校机是 E5-2697 v2（IvyBridge，**没有 AVX2**），光遇本体是
    /arch:AVX2 全局编译，启动即崩；且 X79/LGA2011 平台换任何 CPU 都不支持 AVX2。
  * 2026-09-03（续8）：**学校机换了主板+CPU+内存+显卡之后"可开光遇"**（现 8 核，
    启动打印"限核 2/8"），并做了首次实机全链路（视觉/OCR/AI/发送都通）。
  * 2026-10-06：用户确认上面这条就是现状 —— **换过 CPU+主板，能开光遇；
    核心比以前少（8），但单核性能更强。**

  => 第十一章里"学校 24 线程"那句是 9/1 写的、**已过时**；现在按 8 核算。
  => **这次在学校可以直接做真机验收**（第一节），第二节的离线清单留着备用
     （比如游戏没开、或临时只想改代码时用）。

【利好】单核强对这个项目很关键：交接文档记过，**OCR 单次推理延迟由单核性能主导**
（当年学校那条是"E5-2697 v2 + 限 2 核 → 中位 0.8 秒"）。所以换机后 OCR 应该明显变快，
很可能接近家里水平。

【学校专属：两条别当成 bug 的差异】
1) `[PD] 进程已限核 4/8，优先级低于游戏` —— 家里是 8/16。
   限核数是 `max(2, min(n-1, n//2))` 算出来的，8 逻辑核 -> 4 核，**正常**。
   想调：设 `SKY_LIMIT_CORES`。
2) 窗口尺寸要重新确认：模板是按 1920x1080 标定的，而**每台机器的窗口坐标/尺寸不同**
   （项目文档"换电脑后要改的地方"第一条就是这个）。启动后确认那行
   `窗口(客户区): 1920x1080`，并且是 16:9；不对就用 `py window_fix.py` 先预演。

一、学校能开光遇 -> 真机验收（优先级从高到低，本次重点）
--------------------------------------------------------
直接双击 start_all.bat 选 [1]，然后按「回家操作说明.txt」第七节的 A~D 走：
  A【最要紧】「发呆」修复（第四十一/四十二章）
      动作（躺下/抱抱）之后面板该**立刻**重开，不再等守门 1.2s 迟滞 + 5s 确认。
      若反而更乱：在 start_loop_v5.bat 里加 set SKY_REOPEN_AFTER_ACTION=0 回退。
  B 纯 CHAT 发送后面板不再被误判关（[hint=...] 应保持 0.8x/open）
  C 抱抱回归（按 F 1 次、不再 2.7s 补按、空格前复查主动分 = 0.9x）
  D 长跑 >=10 分钟不打断（家里跑过 13.9 / 19.4 分钟两次零崩溃，这次是回归）

启动后同样要确认三行：
  [PD] OCR 引擎: PP-OCRv5 + DmlExecutionProvider
  [PD-Sense] 截屏后端: bettercam/DXGI（对游戏零干扰，N 块屏）   <- 之后不该再出现 mss/GDI
  窗口(客户区): 1920x1080

跑完把 logs/loop_*.txt 带回家（或用微信传回）。

六、两件容易忘的
--------------------------------------------------------
* **Arduino 要插好**：学校是 COM4（自动探测，不用手改）。续8 记过坑：换主板后一度
  枚举失败（CM_PROB_PHANTOM），**换后置 USB2 口 + 换一根能传数据的线**就好了。
  Arduino 一断，表现是"不自动开面板、不发消息"（因为按 C 和发消息都走它）。
* **AVX2 补丁现在不需要了**：当年为了绕过"处理器未达最低配置"给学校的
  `D:\FeverGames\...\FeverGamesInstaller.exe` 打过 AVX2 补丁（桌面 `光遇AVX2补丁\`）。
  换了支持 AVX2 的 CPU 之后**补丁本身无害**（只是把检测无条件放行），
  想还原就跑桌面那个 `还原原版_双击.bat`（会从 `.avx2bak` 恢复）。不急，别为此特意折腾。
* **【钱】API 余额**：日志出现 `HTTP 402 Insufficient Balance` 就是余额不足，
  表现是"前面正常、之后完全不回话"。见过一次，别当 bug 查半天。
